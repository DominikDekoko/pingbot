### Задание на разработку бота для упоминания определенной группы участников в беседе. 

## Задумка 

Мы делаем простого бота для телеграм, который позволял бы пользователю по вводу фразы например "я иду домой" упомянуть в беседе определенную группу людей, которую он заранее зарегистрировал в личных сообщениях с ботом. 


## глоссарий

Пингануть - упомянуть

## Сценарий использования. 

Пользователь регистрируется в боте (нажимает кнопку старт) -> Вводит название группы (дота 2) -> сбрасывает одним сообщением через пробел список юзернеймов для упоминания (@us1 @us2 @us3) -> Эту информацию бот сохраняет у себя для дальнейшего использования. -> пользователь добавляет бота в чат, и при написании ключевой фразы "я иду домой дота 2" (кодовая фраза которую пользователь задает + название группы), бот пингует определенную группу. При этом должна быть реакция на ключевое слово @all, чтобы пингануть всех участников беседы.
